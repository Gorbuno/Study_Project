## О репозитории

Этот репозиторий является **портфолио учебных работ**. Каждая папка соответствует отдельной дисциплине и содержит:
- **Исходный код** (`.cpp`, `.java`, `.py`, `.h` и др.)
- **Отчёты в формате PDF** с описанием постановки задачи, алгоритмов, тестированием и выводами
- **Скрипты сборки** (`.sh`, `.pro`) и файлы конфигурации

&gt; 💡 **Для чего это нужно?**  
&gt; Репозиторий демонстрирует прогресс от базовых консольных приложений до многопоточных клиент-серверных систем с GUI, а также охватывает низкоуровневое программирование, алгоритмы, компьютерную графику и защиту информации.

## OOP — Объектно-ориентированное программирование

**Язык:** C++ (стандарт C++11/14), фреймворк **Qt**  
**Платформа:** Linux / Windows

Цикл работ посвящён созданию **калькулятора квадратных матриц** с постепенным усложнением архитектуры: от консоли до клиент-серверного GUI-приложения.

| Работа | Что реализовано | Ключевые технологии |
|--------|-----------------|---------------------|
| **PR_1** | Консольное приложение. Класс `SquareMatrix` над вещественными числами. Вычисление определителя, транспонирование, ранг. Использование абстрактного типа `number` (через `typedef`) для обеспечения инвариантности реализации. | ООП, шаблоны типов, консольный интерфейс |
| **PR_2** | Расширение PR_1 на множество **комплексных чисел**. Разработан класс `TComplex`. | Перегрузка операторов, дружественные классы |
| **PR_3** | GUI-приложение на **Qt** для работы с матрицами над **рациональными числами** (`TRational`). Графический ввод/вывод, отображение матрицы в виджетах. | Qt Widgets, сигналы/слоты, GUI-дизайн |
| **PR_4** | **Клиент-серверная архитектура**. GUI-клиент (Qt) + консольный сервер. Обмен данными по **UDP** (Qt Network). | UDP-сокеты, сериализация, разделение логики |
| **PR_5** | Тот же клиент-сервер, но связь по **TCP** (с установлением соединения). | TCP-сокеты, `QTcpServer` / `QTcpSocket` |
| **PR_6** | Клиент-сервер на TCP с использованием **шаблонов C++** (`template`). Матрица над комплексными числами. | Шаблоны, метапрограммирование |
| **PR_7** | Добавлена **сериализация/десериализация** матриц: сохранение в файл и загрузка. Расширение TCP-сервера. | Файловый ввод/вывод, потоки Qt |
| **PR_8** | Введена **многопоточность** на стороне сервера: параллельная обработка нескольких клиентских запросов. | `QThread`, потокобезопасность |

> 📄 Каждая папка содержит PDF-отчёт с UML-диаграммами, описанием классов и тестами.

## OC — Операционные системы

**Язык:** C++  
**Платформа:** Linux (POSIX)

Работы направлены на изучение **многопоточного и многопроцессного программирования**, механизмов синхронизации и межпроцессного взаимодействия (IPC).

| Работа | Тема | Что изучается |
|--------|------|---------------|
| **LR_1** | Потоки POSIX (`pthread`) | Создание потоков, передача параметров, флаги и коды завершения |
| **LR_2** | Синхронизация | `pthread_mutex_lock` / `trylock` / `timedlock`, `pthread_spin_lock`, `sem_wait` / `trywait` / `timedwait` |
| **LR_3** | Процессы | `fork()`, родительский и дочерний процессы, обмен данными |
| **LR_4** | Разделяемая память | `shm_open`, `mmap`, семафоры для синхронизации доступа |
| **LR_5** | Сигналы | Обработка сигналов (`signal`, `sigaction`), асинхронное взаимодействие |
| **LR_6** | Неименованные каналы | `pipe()`, двунаправленный обмен между родственными процессами |
| **LR_7** | Именованные каналы (FIFO) | `mkfifo()`, взаимодействие независимых процессов |
| **LR_8** | Сокеты | Клиент-серверное приложение на сокетах (TCP/UDP), сетевое взаимодействие |

> 🔧 Каждая лаборатория сопровождается bash-скриптом сборки (`*.sh`).
